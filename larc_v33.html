패턴 범례 — P1–P6 Clinically Actionable Phenotypes
P1: DM↑↑ + LR↑↑ — 복합최고위험
P2: DM↑↑ + LR↑ — Systemic 우선
P3: DM↑↑ + LR↓ — RT de-escalation
P4: LR↑↑ dominant — CRT 국소 우선
P5: Balanced Intermediate — 표준 TNT
P6: DM↓ + LR↓ — Upfront TME 고려
🧬
dMMR / MSI-H 직장암 — 별도 치료 트랙 적용 (P1–P6 매트릭스와 독립) 진단 시 MMR/MSI 검사를 반드시 시행하세요. dMMR/MSI-H 확인 시 PD-1 inhibitor 기반 비수술적 전략을 MDT에서 우선 검토합니다. 약제 접근성, 급여 조건, 환자 선호를 함께 고려 (Cercek et al., NEJM 2025 · ESMO Guideline 2025).
⚡ Hierarchical Override Rule — 판정 원칙
DM-High factor ≥ 1개→ DM-risk = HIGH (개수 불문)
DM-High 없음 + DM-Int ≥ 1개→ DM-risk = INTERMEDIATE
DM-High, Int 모두 없음→ DM-risk = LOW
LR-High factor ≥ 1개→ LR-risk = HIGH (개수 불문)
LR-High 없음 + LR-Int ≥ 1개→ LR-risk = INTERMEDIATE
LR-High, Int 모두 없음→ LR-risk = LOW
📡
